# Hyper-Photon

This is a very new project and is continuously in development.

For now, this language only has <B>12 keywords</B>. In future updates, more keywords will be added.
This is a language that brings the easy syntax of python with the native execution speed of C++. It uses a transpiler that converts `Hyper-Photon` to `C++23`.


The keywords are:

- `-print()`
- `-println()`
- `-sqrt()`
- `-floor()`
- `-ceil()`
- `-abs()`
- `-sin()`
- `-cos()`
- `-tan()`
- `-asin()`
- `-acos()`
- `-atan()`
